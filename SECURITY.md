# Security policy

Please do not publish exploitable details about a third-party target in public issues.

For a report concerning ZEROFACTOR itself, contact the repository owner through a private GitHub security advisory where available. Include affected version/commit, reproduction steps, impact, and a suggested mitigation. Do not include customer secrets or unrelated personal data.

ZEROFACTOR is currently an early-stage foundation and must not be relied upon as a production security certification or as the sole control protecting any system.
