# ZEROFACTOR local dashboard

Open dashboard/index.html in a modern browser. Import a JSON report generated by the CLI.

The current local workspace adds:
- browser-local project records;
- per-project imported assessment history;
- a local Owner / Analyst / Viewer presentation profile;
- report metrics, findings, dependencies, checks and warnings.

Important security boundary: this dashboard currently uses browser localStorage. The role selector is a UI convenience only; users can edit browser storage or bypass client-side checks. It is NOT authentication, secure RBAC, access control for APIs, multi-tenant isolation, encrypted server storage or an audit trail. Do not store confidential reports or use this interface for multiple users until a server-side identity and authorization backend is implemented.

The local project history is stored in the current browser profile and is not synchronized between devices. Clearing browser data can delete it. No report is uploaded by the dashboard.
